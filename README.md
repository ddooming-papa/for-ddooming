# 영현정&뚜밍 가족 홈페이지 🎀

우리 뚜밍이의 두 번째 생일을 기념하는 우리 가족만의 홈페이지입니다.

## 📁 폴더 구조

이 폴더에 아래 파일들을 함께 넣어주세요:

```
family-page/
├── index.html          ← 메인 페이지 (이미 준비됨)
├── README.md           ← 이 파일
│
├── bgm.mp3             ← 배경음악 (직접 준비)
│
├── letter-mom.mp4      ← 엄마가 뚜밍에게 영상편지
├── letter-dad.mp4      ← 아빠가 뚜밍에게 영상편지
├── letter-baby.mp4     ← 뚜밍이의 한마디
│
├── photo1.jpg          ← 갤러리 사진 1
├── photo2.jpg          ← 갤러리 사진 2
├── photo3.jpg          ← 갤러리 사진 3
├── photo4.jpg          ← 갤러리 사진 4
├── photo5.jpg          ← 갤러리 사진 5
└── photo6.jpg          ← 갤러리 사진 6
```

## 🎨 페이지 구성

1. **메인 인사** — 영현 ♡ 현정 ♡ 뚜밍, 타이핑 효과로 메시지 표시
2. **카운트다운** — 2026년 6월 8일까지 실시간 카운트
3. **영상편지** — 엄마/아빠/뚜밍 영상 3개
4. **추억 갤러리** — 6장의 가족 사진
5. **타임라인** — 뚜밍이의 성장 기록
6. **편지** — 부모가 뚜밍에게 보내는 편지 (직접 수정 가능)

## 🎵 배경음악 추가하기

1. 좋아하는 음악 파일을 `bgm.mp3` 이름으로 변환
2. 이 폴더에 그대로 넣기
3. 페이지 우측 상단의 🎵 버튼을 누르면 재생

> ⚠️ 저작권 있는 음악은 GitHub Public 레포지토리에 올리지 않는게 좋아요.
> 직접 만든 음악이나, 무료/CC 라이선스 음악(예: YouTube Audio Library)을 추천드려요.

## 🎬 영상편지 추가하기

세로 영상도 가로 영상도 모두 들어갑니다.
파일 이름만 정확히 맞춰주세요:
- `letter-mom.mp4`
- `letter-dad.mp4`
- `letter-baby.mp4`

## 🖼️ 사진 추가하기

`photo1.jpg` ~ `photo6.jpg` 이름으로 넣어주세요.
정사각형 비율로 보이지만 다른 비율도 자동으로 맞춰져요.

## 📝 내용 수정하기

`index.html` 파일을 메모장이나 VSCode로 열어서:
- 타임라인 내용 수정 (각 날짜와 설명)
- 편지 내용 수정 (`<!-- ============ LETTER ============ -->` 섹션)
- 타이핑 메시지 수정 (`typingMessages` 배열)

## 🚀 GitHub Pages 배포 방법

1. GitHub에서 새 레포지토리 생성 (예: `our-family`)
2. 이 폴더의 모든 파일을 업로드
3. 레포지토리 → Settings → Pages
4. Source: `Deploy from a branch` 선택
5. Branch: `main`, Folder: `/ (root)` 선택 후 Save
6. 잠시 후 `https://[username].github.io/our-family/` 주소로 접속 가능!
